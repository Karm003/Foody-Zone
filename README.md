# 🍔 Foody Zone

A modern food discovery web application built with React, TypeScript, Tailwind CSS, and Express.js. Users can browse and search food items through a clean, responsive, and user-friendly interface.

## 🚀 Features

* 🔍 Search food items instantly
* 📱 Fully responsive design
* 🎨 Modern UI with Tailwind CSS
* ⚡ Fast frontend powered by React and Vite
* 🔧 Backend API built with Express.js
* 📝 Type-safe development using TypeScript

## 🛠️ Tech Stack

### Frontend

* React
* TypeScript
* Tailwind CSS
* Vite

### Backend

* Express.js
* Node.js
* TypeScript

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/Karm003/Foody-Zone.git
cd Foody-Zone
```

### Install Dependencies

Frontend:

```bash
cd client
npm install
```

Backend:

```bash
cd server
npm install
```

## ▶️ Running the Application

### Start Frontend

```bash
cd client
npm run dev
```

### Start Backend

```bash
cd server
npm run dev
```
